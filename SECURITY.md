# Chính sách bảo mật - Lotus Share

## Báo cáo lỗ hổng

**Không** mở Issue công khai cho lỗ hổng bảo mật. Dùng một trong hai kênh riêng tư:

1. GitHub: tab **Security** của repo `tsudev-org/lotus-share` > **Report a vulnerability** (Private vulnerability reporting).
2. Trang liên hệ của hệ sinh thái: <https://tsudev.com>.

Vui lòng gửi: phiên bản, hệ điều hành, các bước tái hiện, mức ảnh hưởng. Chúng tôi phản hồi trong 72 giờ và
công bố bản vá kèm ghi công (nếu bạn muốn).

## Phiên bản được hỗ trợ

Chỉ bản phát hành mới nhất tại <https://github.com/tsudev-org/lotus-share/releases/latest>.

## English summary

Do **not** open a public issue for a vulnerability. Report it privately via GitHub **Security > Report a
vulnerability** (<https://github.com/tsudev-org/lotus-share/security/advisories/new>). Include the version, operating
system, steps to reproduce and impact. We reply within 72 hours, fix critical issues as a priority and credit the
reporter in the release notes if they wish. Only the latest release is supported.
