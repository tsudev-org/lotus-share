## 2. Đánh giá

- Cả ba engine là phân loại bằng học máy, nhãn chung không tên họ mã độc => dấu hiệu báo nhầm điển hình cho tệp
  thực thi MỚI, CHƯA KÝ Authenticode (bộ cài Inno Setup; CLI Rust ARM64). Không có engine dựa trên chữ ký nào gắn cờ.
- Nguồn gốc kiểm được: tệp dựng trên GitHub Actions từ nhãn `v26.11.1801`, `gh attestation verify` đạt, SHA256SUMS ký
  Sigstore. Bản 2.0.0-lotus.7 chưa từng được quét nên không có mốc so sánh.
- Gốc rễ lâu dài: ký Authenticode (P4 phiếu P2 - SignPath khi đủ ngưỡng, hoặc Certum).
